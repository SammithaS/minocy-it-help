# Install or update software

Use this when you need to install an approved app, update one, or you're asked for an administrator password to install something.

**Don't install software from random websites. If an installer asks for an admin password, stop and use {{software_centre}} or raise a request.**

## Symptoms

- You need an app that isn't on your laptop
- An installer asks for an administrator username and password
- An app says it needs to be updated

## Quick fixes

1. On Windows, open **{{software_centre}}** from the Start menu. On Mac, open **Self Service** from Applications.
2. Search for the app, click **Install**, and wait — it installs without needing admin rights.
3. Restart the app (or the laptop, if asked) when the install finishes.
4. To update an app, open {{software_centre}} → Updates (or Self Service → Updates) and install what's listed.

## Advanced steps

1. If an install fails, restart the laptop, connect to {{wifi_ssid}} or {{vpn_name}}, and try again — installs need the {{company}} network.
2. Check you have at least 10 GB of free disk space before installing large apps.

## Escalate when

- The app you need isn't in {{software_centre}} or Self Service — raise a software request with the app name and why you need it
- The install fails twice with an error code (include the code in the ticket)
- The app needs a paid licence (your manager will be asked to approve)
