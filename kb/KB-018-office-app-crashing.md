# Excel, Word or another app keeps crashing

Use this when an app like Excel, Word or PowerPoint freezes, shows "Not responding", or closes on its own.

## Symptoms

- The app closes without warning or shows "has stopped working"
- "Not responding" when opening or saving a file
- It crashes only with one particular file
- It won't open at all

## Quick fixes

1. Save your work in other apps, then close the app fully and open it again.
2. Restart the laptop.
3. Check whether it crashes with every file or just one. If just one, open a copy of it from OneDrive on the web.
4. Install pending updates from {{software_centre}} (Windows) or Microsoft AutoUpdate (Mac).
5. Start the app in safe mode to rule out add-ins: hold **Ctrl** while opening it on Windows and click Yes.

## Advanced steps

1. If safe mode works, turn off add-ins: File → Options → Add-ins → Manage COM Add-ins → Go, and untick them one at a time.
2. Repair Office on Windows: Settings → Apps → Installed apps → Microsoft 365 → Modify → **Quick Repair**.
3. Make sure you have at least 10 GB of free disk space.

## Escalate when

- The app still crashes after a Quick Repair
- An important file is corrupted or won't open anywhere (raise as HIGH if there's a deadline)
- Several people have the same crash after an update
- A business app other than Microsoft 365 crashes — include the app name and any error message
